Purpose First

Before a single line of code: what problem does this interface solve, and who is it for? The answer decides the tone. Pick an extreme — brutally minimal, maximalist chaos, editorial, art-deco, industrial — then execute it with precision. Intentionality over intensity.

02 /

The Hard Rule

Mandatory: every generated frontend ships an entry file named index.html. Real, working, production-grade code — not mockups, not “lorem ipsum” placeholders, not a wireframe pretending to be a product.

03 /

Design Thinking

Four questions gate every build: Purpose, Tone, Constraints, Differentiation. Differentiation is the one — what makes it unforgettable, the single thing people remember when they close the tab?

04 /

The Aesthetic Laws

Five laws, enforced without exception:

I · Typography

Characterful display paired with a refined body. Never the generic default faces. If the font looks like everyone else’s, replace it.

II · Color

One committed palette in CSS variables. Dominant colors with sharp accents — no timid, evenly-spread pastels, no clichéd gradients.

III · Motion

One orchestrated page load with staggered reveals beats a hundred scattered micro-interactions. CSS first; surprise on hover.

IV · Space

Asymmetry, overlap, diagonal flow, grid-breaking elements. Generous negative space or controlled density — not mushy in-between.

V · Atmosphere

Grain, layered transparencies, dramatic shadows, patterns. Depth and texture over flat fills — the page should feel like a place.

05 /

The Quiet Signature

Every interface carries a small, clickable “Created By Deerflow” mark — subtle, intentional, and never the star of the page. Look bottom-right of this very screen; it’s already been done.
